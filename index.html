PostgreSQL Backups

Personal backup application

A private copy.
A safer recovery.

PostgreSQL Backups stores the owner's readable SQL database backups privately in Google Drive.

How it works

Once daily at 22:35 UTC (04:05 India time), a native cron job on the owner's database server exports PostgreSQL databases and roles as plain SQL files and uploads them using rclone. Backup checks and isolated restore tests help confirm that the saved data can be recovered.

The SQL files are not encrypted by the app. The backup folder is private in the owner's Google Drive. Temporary exports and restore work stay on the server and are cleaned after each run; retained backups are stored only in Google Drive.

The backup policy keeps three days of backups and always at least the latest successful backup. Retention cleanup follows successful backup verification.

Limited Google Drive access

The app requests the drive.file permission. It accesses backup files and folders it creates; it does not request access to the owner's other existing Drive files.

This is a personal utility operated by its owner. There is no public database viewer or account registration on this website.
