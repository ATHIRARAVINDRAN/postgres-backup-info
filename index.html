PostgreSQL Backups

Personal backup application

A private copy.
A safer recovery.

PostgreSQL Backups stores the owner's retained encrypted database backups in Google Drive.

How it works

Every six hours, a scheduled job on the owner's Raspberry Pi exports PostgreSQL databases, encrypts the backups with restic, and uploads them using rclone. Backup checks and isolated restore tests help confirm that the saved data can be recovered.

The Pi's SSD is used for temporary export and restore work and a restic metadata cache. Temporary database files are cleaned after each run; no backup repository is retained on the Pi.

The backup policy keeps snapshots from the latest 72 hours and at least the last successful snapshot. Retention cleanup follows successful backup verification.

Limited Google Drive access

The app requests the drive.file permission. It accesses backup files and folders it creates; it does not request access to the owner's other existing Drive files.

This is a personal utility operated by its owner. There is no public database viewer or account registration on this website.
