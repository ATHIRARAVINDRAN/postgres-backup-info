PostgreSQL Backups

Last updated 19 October 2026

Privacy policy

PostgreSQL Backups is a personal backup application operated by its owner, for the owner's own database backups.

Google account access

The app requests only the Google Drive https://www.googleapis.com/auth/drive.file scope. It uses this permission to create, read, update, and delete its own backup files and folders. It does not request access to unrelated existing files in Google Drive, Gmail, contacts, or calendars.

Data the app handles

The app handles database exports, PostgreSQL role definitions, backup metadata, and the Google OAuth credentials needed to upload and maintain those backups. A native cron job on the owner's database server creates readable, unencrypted SQL files and uploads them to a private folder in the owner's Google Drive. The SQL files contain database contents and may include role password hashes; anyone with access to the files can read them.

Retained backups are stored only in Google Drive. Temporary exports and isolated restore work are kept on the database server and cleaned after each run. The backup job does not depend on the owner's Raspberry Pi or Mac.

OAuth tokens and database credentials are kept in access-restricted storage on the owner's server. They are not published on this website or included as public repository content.

How data is used and shared

Data is used only to create, verify, retain, and recover the owner's backups. Backup data is processed temporarily on the owner's server and retained in the owner's Google Drive. It is not sold, used for advertising, used to train AI models, or shared with other parties by this application.

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The configured policy keeps three days of backups and always at least the latest successful backup. Old backup sets are removed after successful backup verification. Failed jobs or unavailable storage may delay cleanup.

The owner can revoke access in their Google Account third-party connections. Revocation prevents future authenticated uploads but does not itself delete existing backup files. The owner can delete the app's backup folder in Google Drive if desired. Google Drive's own trash and deletion policies may also apply.

This information website

This static website is hosted on GitHub Pages. It contains no analytics, advertising, cookies set by the app, or tracking scripts. GitHub may process ordinary request information as the website host under its own privacy policy. The website does not receive database contents or OAuth tokens.

Questions and changes

Privacy questions can be raised through the information repository. Do not include private data or credentials in a public issue. Changes to this policy will appear here with an updated date.
